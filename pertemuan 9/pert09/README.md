# Praktikum PBO 09 — Arsanti Nur Indriani
**NPM:** 4525210128  
**Proyek:** Sistem Perpustakaan Java Console

## Menjalankan
Dari folder `java`:
```bash
mvn clean compile
mvn exec:java
```
Java 25 LTS dan Maven 3.9+ diperlukan sesuai modul praktikum. Maven mengunduh Apache Commons Lang 3.17.0, yang digunakan pada `Main.java` melalui `StringUtils.capitalize`.

## Struktur
`src/main/java/id/ac/univpancasila/perpustakaan/` berisi `Main.java`, package `model`, `service`, dan pada pertemuan 10 package `exception`.
